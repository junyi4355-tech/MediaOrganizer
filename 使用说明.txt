素材整理工作流 · 使用说明
====================================

一款便携式(免安装)的照片/视频素材整理工具。双击 MediaOrganizer.exe 即可运行,
整个 MediaOrganizer 文件夹拷走就能用(注意: _internal 目录是运行库, 必须一起拷)。

本版界面是**多卡片工作流编辑器**: 自己摆"来源卡", 需要时插"文件夹卡"(只作一层目录),
在最末端挂"输出卡"(决定收哪些文件), 点接线柱连线, 运行时光点沿连线流动。


一、三种卡片
------------------------------------
  ➕ 来源卡    —— 链路的根: 选一个素材文件夹 + 一个"输出根目录"。只有右侧【出】接线柱。
  📁 文件夹卡  —— **纯目录层级**, 只有一个名字(你填什么就是什么), 不筛选、不收文件。
                  相当于在两层之间夹了一层文件夹; 必须**在它后面再接输出卡**才收文件。
  📦 输出卡    —— 真正落盘的那张: 决定收 照片 / 视频 / 其他, 或自定义后缀(可填多个)。

  每张卡左边一个【入】、右边一个【出】(来源卡只有【出】)。
  点一张卡的【出】, 再点另一张卡的【入】就连上了 —— 任意两张卡都能这么接。


二、三步上手
------------------------------------
  1. 右侧【➕ 添加来源卡】—— 选素材文件夹, 再选输出根目录
     → 自动建好并连好 3 张末端输出卡: 照片 / 视频 / 其他
  2. (可选)想加一层目录: 点【📁 添加文件夹卡】, 只填一个文件夹名(例如 无人机 / 客户A),
     它就插在来源卡后面; 再把它右边的【出】接到一张输出卡上, 于是变成
         输出根/无人机/视频/<日期>/xxx.mp4
  3. 点【▶ 运行工作流】

  输出结构示例:
    输出根/照片/2025-03-27/xxx.jpg
    输出根/视频/2025-03-27/xxx.mp4
    输出根/其他/2025-03-27/xxx.txt
    输出根/无人机/视频/2025-03-27/xxx.mp4   ← 文件夹卡 + 输出卡形成的两级


三、链路规则(重要)
------------------------------------
  · **离来源越远 = 越深的一层子文件夹**; 每张卡右上角写着它的级数(第1级、第2级…),
    同级就是同一层, 一键整理会把同级卡排在同一列。
  · **只有输出卡会落盘**, 而且只有"链路末端"的那张; 中间的卡只贡献一层文件夹名。
  · **接线方向自动判定**: 两张卡级数不同时, 离来源更近的那张自动作上一级(你点哪根先都一样);
    只有两张卡同级时, 才按你点的先后定(先点【出】的那张作上一级)。
  · 每张卡的【入】只能接一个上一级(重接 = 换上一级); 【出】可以接多个下一级; 不允许成环。
  · 没接在来源卡上的卡片会标"未接入", 运行时被跳过(不影响其余卡片), 也可以直接删掉。


四、分类与归档规则
------------------------------------
  输出卡的筛选方式:
    · 照片 —— jpg/png/gif/webp/heic/raw 等图片
    · 视频 —— mp4/mov/avi/mkv/webm 等视频
    · 其他 —— 剩余杂项文件
    · 自定义后缀 —— 自己填, 可多个(如 .dng, .arw); 这类输出卡**独占**这些后缀,
                    照片/视频/其他 不会重复收它们(同一个文件不会被拷两份)

  每张输出卡内部按日期归档(顶部"全局精度"可选 年 / 年-月 / 年-月-日, 默认到日):
    照片优先读 EXIF 拍摄时间, 其余取文件修改时间

  顶部【方式】: 复制(保留原文件, 默认) / 移动
  文件名冲突自动加序号, 绝不覆盖已有文件。


五、卡片与连线的小操作
------------------------------------
  · 拖动卡片时, 连线会实时跟着卡片走
  · 点一个【出】接线柱(会变亮黄), 再点另一张卡的【入】就连上了;
    再点同一个接线柱 = 取消; 点空白处也取消
  · 鼠标靠近某条连线, 线中点会浮出一个红色 ✕, 点它即删掉这条连线
    (在连线上点右键也有"删除这条连线 / 删除下游卡片"菜单)
  · 双击来源卡: 改素材文件夹 / 改输出根目录
  · 双击或右键文件夹卡: 改文件夹名
  · 双击输出卡: 给它单独指定输出位置(默认跟随来源卡的输出根目录)
  · 右键输出卡: 加急 / 删除; 卡片右上角 ✕ 也能删除


六、运行中
------------------------------------
  · 只有末端输出卡会落盘; 日志里每条链都会打印解析结果, 例如
      🔗 链路: 素材 → 无人机 → 视频  ⇒  输出/无人机/视频
  · 整条链的连线会一起发光流动(不是只有最后一段有动画)
  · 最多 3 路同时传输, 视频大文件单独占 1 路
  · 每张末端输出卡显示进度百分比, 底部日志逐文件显示"正在拷贝… 100% √ 完成"
  · 运行按钮变红后可【暂停】/【中断】


七、旧版界面(稳定版数据光带工作流)
------------------------------------
  如果你更习惯"选两个文件夹就完事"的旧版: 在 exe 所在目录打开 PowerShell, 运行
      .\MediaOrganizer.exe --classic
  旧版是固定三类 + 素材源居中 + 左右目标文件夹对称自动连线, 用法是三步:
  选输入文件夹 → 选输出文件夹 → 点【▶ 运行工作流】。


八、黑屏 / 花屏时的兜底
------------------------------------
  程序默认优先用 GPU(OpenGL) 渲染, 并在启动 150ms 后自检: 如果显卡/驱动交不出画面,
  会自动切回软件渲染(日志里会写一行"GPU 探测: ... -> 回退软件渲染")。
  若仍不正常, 手工强制软件渲染: 在 exe 旁新建一个**空文件**并命名为
      MediaOrganizer.raster
  然后重新打开程序即可。


九、程序在 exe 旁生成的文件
------------------------------------
    startup.log         —— 诊断日志: 启动/退出打点、渲染自检结论、被拦截的异常及调用栈
    _smoke_result.txt   —— 只有在跑 --smoke-leave 自检时才会生成
    MediaOrganizer.ini  —— 记住上次用的文件夹(便携配置, 不写注册表, 可随时删)
  遇到异常请把 startup.log 发出来; 若系统弹过错误, 另附
  事件查看器(eventvwr) → Windows 日志 → 应用程序 → MediaOrganizer 的
  "错误模块名称 + 异常代码"。

⚠ 中断或关窗会丢失未拷完的部分; 跑到进度 100% 即完整落盘。
⚠ 便携版必须整个文件夹一起拷: exe 旁边的 _internal 目录是运行库, 只拷 exe 会打不开。
